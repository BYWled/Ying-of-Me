欢迎来到 Vue.js 的世界。

这篇文章写给已经掌握 HTML/CSS/JS 基础，想要进一步学习现代前端框架的读者：

  • 你知道 HTML 是结构、CSS 是样式、JS 是行为；
  • 你听说过”框架”这个词，但还没真正用过；
  • 你想知道为什么不能只靠原生 JS 写页面，框架到底解决了什么问题。

所以本文会按这个顺序来：

  1. 先理解 Vue 是什么、解决了什么问题
  2. 搭建开发环境，跑起第一个 Vue 项目
  3. 学习模板语法和响应式数据
  4. 掌握计算属性、侦听器等核心概念
  5. 进入组件化开发的世界
  6. 最后做一个完整的 Todo 应用

本文基于 Vue 3（当前最新稳定版本）编写，使用 Composition API 风格。
如果你在网上看到 data()、methods: 这种写法，那是 Vue 2 的 Options API，两者都能用，但 Composition API 是官方推荐的新范式。

一、Vue 是什么？为什么需要它？

1.1 框架的诞生背景

在学 HTML/CSS/JS 的时候，你可能已经遇到过这些痛点：

  • 想要列表数据变化后页面自动更新，你得手动获取 DOM、拼接 HTML、重新插入；
  • 多个地方用同一份数据，你得逐个找到对应的 DOM 元素逐一修改；
  • 页面逻辑变复杂后，代码到处都是 document.querySelector 和 innerHTML，难以维护。

Vue（读音 /vjuː/，类似于 view）就是为了解决这些问题而生的。

Vue 的核心理念：数据驱动视图。你只需要关心数据（状态），Vue 会自动帮你把数据变化同步到页面上。

1.2 Vue 的核心特征

  • 响应式系统：数据变了，页面自动更新，不需要手动操作 DOM
  • 组件化：把页面拆成一个个独立、可复用的组件
  • 模板语法：用类似 HTML 的语法写模板，学习成本低
  • 渐进式：可以只用核心功能做简单的数据绑定，也可以引入路由、状态管理构建大型应用

Vue 是国人尤雨溪（Evan You）在 2014 年创建的，中文文档非常完善，对中文开发者非常友好。

四、响应式数据：Vue 的灵魂

4.1 什么是响应式？

“响应式”是 Vue 最核心的概念。简单来说：

当你修改一个响应式变量的值时，所有用到这个变量的地方（模板、计算属性等）都会自动更新。

这是 Vue 和原生 JS 最大的区别——原生 JS 里变量变了，你得手动去改 DOM；Vue 里变量变了，页面自己就变了。

场景 推荐 原因

简单对象 ref() 或 reactive() 都行 看个人习惯

一个简单的记忆法：**不确定用哪个的时候，就用 ref()**，它适用于所有场景。

五、模板指令系统

Vue 在标准 HTML 的基础上扩展了一套指令（Directive）系统，以 v- 开头，用于在模板中实现条件渲染、列表渲染、属性绑定等功能。

5.1 属性绑定 v-bind（缩写 :）

原理补充

  • v-bind:src 的意思是”把 src 属性的值绑定到 JS 变量 imageUrl“。
  • 当 imageUrl 变化时，src 属性会自动更新，图片也会自动刷新。
  • 缩写 : 是最常用的写法，建议直接记缩写。

5.2 条件渲染 v-if / v-show

v-if 和 v-show 的区别：

特性 v-if v-show
原理 条件为 false 时移除 DOM 节点 始终在 DOM 中，通过 CSS display 控制
初始渲染开销 条件为 false 时无开销 始终渲染
切换开销 高（每次都要销毁/重建） 低（只改 CSS）
适用场景 条件很少改变时 需要频繁切换显示/隐藏时

经验法则：如果一个元素在运行期间很少改变可见性（比如根据用户角色显示不同界面），用 v-if；如果经常切换（比如展开/收起面板），用 v-show。

5.3 列表渲染 v-for

为什么 :key 很重要？

Vue 用 key 来追踪每个节点的身份。当列表数据变化时，Vue 通过 key 判断哪些节点需要新增、删除或移动，而不是盲目地重新渲染整个列表。

建议用数据中的唯一标识（如 id）作为 key，**不要用索引 index**，否则在插入/删除操作时可能导致渲染异常。

5.4 双向绑定 v-model

v-model 是表单元素的双向绑定指令——数据变了输入框更新，输入框改了数据也同步变化：

原理补充

  • v-model 本质上是一个语法糖，它等价于 :value（绑定数据到输入框）+ @input（监听输入事件更新数据）的组合。
  • 不同的表单元素，v-model 绑定的属性和事件不同：
    • input[type="text"] / textarea / select → 绑定 value，监听 input
    • input[type="checkbox"] / input[type="radio"] → 绑定 checked，监听 change

6.1 计算属性 computed

当你需要基于已有数据派生出新数据时，用 computed：

原理补充

  • computed 和普通函数的区别在于缓存：只要依赖不变，多次访问 fullName 不会重复计算，而是直接返回上次的结果。
  • 这就是”计算属性”而不是”计算函数”的原因——它表现得像一个属性（有缓存），而不是一个每次都要执行的函数。

什么时候用 computed，什么时候直接写方法？
如果一个值依赖于其他响应式数据，并且需要在模板中多次使用，用 computed 获得缓存优势。
如果只是需要一个可以调用的函数（比如点击按钮时执行），直接写普通函数即可。

下一步…

如果你已经读到这里，说明你已经掌握了 Vue 的核心基础。建议按这个节奏继续：

  1. 动手改造 Todo 应用：添加”全部/未完成/已完成”筛选功能
  2. 学习 Vue Router：实现多页面切换（单页应用的基础）
  3. 学习 Pinia：Vue 官方推荐的状态管理库（替代 Vuex）
  4. 了解 <slot> 插槽：让组件更灵活、更可复用
  5. 部署你的 Vue 应用：npm run build 后把 dist/ 目录部署到服务器

Vue 的学习曲线相对平缓，核心概念掌握后就能做出不少东西。
记住一个原则：先会用，再理解原理。
不要在初学阶段纠结”响应式是怎么实现的”，先享受数据驱动视图的便利，等到对 Vue 足够熟悉后再去深入源码。
